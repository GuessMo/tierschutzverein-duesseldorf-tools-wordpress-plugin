## 1. Was ist das Anfragen-Dashboard?

Zentrale Stelle für alle Anfragen aus dem Interessentenbogen (Tiervermittlung).

- Jede Anfrage = eine **Konversation** mit dem Interessenten (E-Mail-artiger Verlauf)
- Alles an einem Ort: Kontaktdaten, gewünschtes Tier, Chat-Verlauf, Antworten
- Erreichbar unter **Tiere → Anfragen**

> Merke: Du siehst nur die Anfragen, die du vermitteln darfst (Berechtigung nötig).
> Der Filter-Zustand (z. B. „Offen" oder eine Tierart) wird für dich **gemerkt** —
> beim nächsten Öffnen steht er wieder so da.

---

## 2. Die Liste: So findest du die richtige Anfrage

| Element | Was es tut |
|---|---|
| **Blauer Punkt** | Anfrage ist **offen** — es wartet etwas auf dich |
| **Name + Datum** | Interessent + Zeitpunkt der letzten Nachricht (neueste oben) |
| **Rassen-Filter** (oben) | Alle / Hund / Katze / Kleintier / Vogel |
| **Status-Filter** (Seitenleiste) | Alle / Offen / Beantwortet / Blockiert / Spam / Papierkorb |
| **Suche** | Suchbegriff eingeben → Liste filtert live |

---

## 3. Eine Anfrage öffnen — was du siehst

Eine offene Anfrage (blauer Punkt) anklicken, z. B. **Daniel Weber / Frodo**.

1. **Kopf**: Name, Status (z. B. „Offen"), wer zugewiesen ist
2. **Kontakt**: E-Mail + Telefon des Interessenten
3. **Interesse**: um welches Tier es geht
4. **Tier-Karte**: Bild, Name, Kategorie + Links „Datensatz öffnen" / „Profil ansehen"
5. **Erste Nachricht**: alle Angaben aus dem Interessentenbogen
   (Wohnlage, Erfahrung mit Haustieren, Tierart, Motivation, Datenschutz-Einverständnis)
6. **Chat-Verlauf**: eingehende Nachrichten links, ausgehende rechts

---

## 4. Antworten — die zwei Modi

**Immer per Icon oben links im Schreibfeld zwischen den Modi wechseln:**

| Modus | Wozu | Wird gesendet an |
|---|---|---|
| **Antwort** (Brief-Icon) | Normale Antwort an den Interessenten | E-Mail (per Textbaustein) |
| **Interne Notiz** (Stift-Icon) | Kurze Notiz für dich/Dein Team — **nicht** an den Interessenten | nur intern |

- Text eingeben → **„Antwort senden"** bzw. **„Notiz speichern"**
- Nach dem Senden einer Antwort wird der Status automatisch **„Beantwortet"**
- Eine **interne Notiz** ändert den Status **nicht** — sie ist keine Antwort an den Interessenten

> Die Antwort wird **geduzt** („dein Interesse", Vorname) — so wünschen wir es.
> Der Betreff lautet z. B. „Antwort auf deine Anfrage #123".

---

## 5. Nachrichten bearbeiten & löschen

Neben **eigenen** (ausgehenden) Nachrichten erscheinen Tool-Icons:

- **Bearbeiten** (Stift) → Text ändern, „Speichern"
- **Löschen** (Papierkorb) → Bestätigung „Diese Nachricht löschen?" → Bubble verschwindet

> Interne Notizen und Antworten, die du selbst geschrieben hast, kannst du so nachträglich korrigieren.

---

## 6. Status-Aktionen (oben in der Konversation)

| Aktion | Wann? | Ergebnis |
|---|---|---|
| **Zuweisen** (Dropdown) | Wenn eine Kollegin/ein Kollege die Anfrage übernehmen soll | Person wird „beteiligt" |
| **Absender blockieren** | Werbende/störende Absender | Status „Blockiert"; weitere Anfragen dieser E-Mail werden blockiert |
| **Als Spam markieren** | Offensichtlicher Spam | Status „Spam" |
| **In den Papierkorb** | Duplikat oder erledigt | Aus der Liste entfernt, über Papierkorb-Filter wieder auffindbar |

Alle Aktionen fragen vorher nach (Bestätigungsdialog) — kein versehentliches Löschen.

---

## 7. Kurz zusammen (Cheat-Sheet)

- **Blauer Punkt = offen** → hier anfangen
- **Rassen-/Status-Filter** oben/unten zum Eingrenzen
- **Antwort** per E-Mail, **Interne Notiz** nur für dich
- **Du-Form** in allen Antworten
- Zuweisen, blockieren, Spam, Papierkorb über die Aktionsleiste
